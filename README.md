# Реализовать интерактивный калькулятор для вычисления арифметических выражений

Программа реализует интерактивный калькулятор на Python, поддерживающий вычисление арифметических выражений с вещественными числами, скобками и операциями сложения (`+`), вычитания (`-`), умножения (`*`), деления (`/`) и возведения в степень (`^`).

Поддерживаются унарные знаки, специальные значения `inf` и `nan`, а также символ `_`, позволяющий использовать результат предыдущего вычисления.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Python-polytech/task-7-calculator.git
cd task-7-calculator
```

### 2. Подготовка окружения

Для работы программы требуется Python версии 3.10 или выше. Внешние библиотеки не используются: все необходимые модули входят в стандартную библиотеку Python.

При необходимости можно создать виртуальное окружение.

#### Для Windows:

```bash
python -m venv .venv
.\.venv\Scripts\activate
```

#### Для macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Запуск программы

В корневой директории проекта выполнить команду:

```bash
python main.py
```

Для macOS и Linux при необходимости:

```bash
python3 main.py
```

После запуска программа переходит в интерактивный режим. Пользователь вводит арифметические выражения, а калькулятор выводит результаты их вычисления. Для завершения работы используется команда выхода, предусмотренная в программе.

### 4. Принцип работы программы

Вычисление выражения выполняется в несколько этапов:

1. **Токенизация.** Входная строка разбивается на числа, операторы, скобки и специальные обозначения. Если встречается неизвестный символ, возникает ошибка токенизации.
2. **Проверка скобок.** Проверяется правильность расстановки открывающих и закрывающих скобок.
3. **Синтаксический разбор.** С помощью рекурсивного парсера определяется порядок выполнения операций с учётом приоритетов и ассоциативности операторов. Для возведения в степень используется правоассоциативность.
4. **Вычисление.** После разбора выражения выполняются соответствующие арифметические операции. Отдельно обрабатываются деление на ноль, переполнение при возведении в степень и специальные значения `inf` и `nan`.
5. **Сохранение результата.** Результат успешного вычисления сохраняется и может использоваться в следующем выражении с помощью символа `_`.

Для обработки ошибок предусмотрена собственная иерархия исключений, включающая ошибки токенизации, проверки скобок и синтаксического разбора.


### 5. Пример работы

```text
> 2 + 3 * 4
14.0

> (2 + 3) ^ 2
25.0

> -2 ^ 2
-4.0

> _ + 10
6.0
```
